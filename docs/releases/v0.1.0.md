# ZoneSwitch v0.1.0

发布日期：2026-10-16。本次为源码发布，未执行 Cloudflare 生产部署。

ZoneSwitch 首个版本提供 Cloudflare 多域名服务状态控制台，可统一切换正常服务、维护中和已欠费状态，并恢复原网站入口。

## 新增

- 同步多个 Cloudflare Zone、Worker 自定义域名和 A / AAAA / CNAME 记录，支持按域、关键词、入口类型与状态筛选。
- 单个域名与跨域批量操作，大批量选择自动按每批最多 20 个处理，并展示逐域名结果。
- 独立静态 Worker 展示维护与欠费提示页，支持后台预览。
- 简体中文 / 英文后台，繁体中文 / 日文 / 英文访客提示页及手动语言切换。
- 管理员密码哈希、8 小时会话、登录限流、Origin / CSRF 校验、会话撤销和最近 100 批操作记录。
- 本地演示、Windows 本地密码修改脚本、中英文部署文档与经过隐私检查的界面截图。
- GitHub Actions 与 Cloudflare Workers Builds 两种部署方式，采用 `main` 开发、`release` 生产发布的分支约定。

## 优化增强

- 修改和删除路由前核对归属，保护后台与提示页入口，遇到外部修改或冲突时拒绝覆盖。
- 写入响应异常后重新查询实际路由；无法确认时保留“待核实”，重启后可再次同步确认。
- GitHub Actions 按各 Worker 的部署内容摘要跳过未变化项；Workers Builds 可通过监听路径筛选构建。

## 部署与使用说明

- 首次使用需要配置后台、维护页和欠费页三个 Worker，以及自己的后台域名、账号和 API Token。
- 同一套 Worker 选择一种自动部署方式，生产分支统一使用 `release`。
- 访客提示返回 HTTP 200 HTML；“正常服务”表示路由状态，不包含网站健康检查。
- 欠费状态由管理员手动设置，不读取 Cloudflare 账单或处理收款。
- 批量切换和三个 Worker 的部署均非原子事务，部分失败不会自动回滚已成功项。
- 配置步骤见[中文部署指南](../deployment.md)与[英文部署指南](../deployment.en.md)。
